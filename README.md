# China Trip 2027

## Upload ke Vercel
1. Extract ZIP.
2. Upload folder ini ke GitHub.
3. Import repository ke Vercel.
4. Setelah URL Vercel jadi, 5. Generate ulang QR Code sesuai URL final.

## URL peserta
Format:
`https://china-trip-2027.vercel.app/?id=septino`
